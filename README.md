# 무의식 관심사 퀴즈

15개의 질문으로 **스스로 의식하지 못했던 관심의 결**을 짚어보고, 그에 맞는 책을 추천하는 단일 HTML 웹앱입니다.

> "나는 이런 걸 좋아해"는 대개 의식이 나중에 붙인 설명입니다.
> 이 퀴즈는 고르려고 고민하기 전에 이미 일어난 반응을 묻습니다.

## 실행

빌드도 설치도 필요 없습니다. `index.html`을 브라우저에서 열면 끝입니다.

```
open index.html          # macOS
start index.html         # Windows
```

GitHub Pages로 배포하려면 저장소 Settings → Pages에서 브랜치를 지정하기만 하면 됩니다.

## 무엇을 보여주나

| 단계 | 내용 |
|---|---|
| 퀴즈 | 15문항, 각 4지선다. 키보드 `1`~`4`로도 응답, `←`/`Backspace`로 이전 문항 |
| 분포 | 6가지 결의 점수를 막대로 표시 |
| 그림자 | 가장 낮게 나온 결과 그것이 의미하는 바 |
| 자기 점검 | "이 알아차림이 정말 무의식에서 온 걸까?" 5개 항목 체크리스트 |
| 책 추천 | 주 유형 3권 + 그림자 1권 + 무의식 자체를 다룬 3권 |

결과는 서버로 보내지도, 브라우저에 저장하지도 않습니다.

## 6가지 결

| 코드 | 이름 | 한 줄 |
|---|---|---|
| `E` | 탐구자 | 모르는 채로는 견디지 못하는 사람 |
| `C` | 창조자 | 머릿속에 있는 걸 기어이 꺼내놓는 사람 |
| `N` | 연결자 | 방 안의 공기를 가장 먼저 읽는 사람 |
| `G` | 수호자 | 무너지지 않게 붙들고 있는 사람 |
| `P` | 개척자 | 경계선을 보면 넘고 싶어지는 사람 |
| `M` | 관조자 | 의미가 없으면 끝내 움직이지 못하는 사람 |

## 채점 방식

한 유형이 유리해지지 않도록, **6가지 결이 정확히 10번씩 선택지로 등장**하도록 문항을 설계했습니다
(15문항 × 4선택지 = 60칸 ÷ 6유형 = 10칸). 각 질문은 6개 중 4개 유형만 담고, 빠지는 두 유형의 조합은
K6 그래프의 1-factorization을 따라 배치해 모든 유형이 정확히 5번씩 빠집니다.

따라서 점수는 단순 합계가 아니라 **"고를 기회가 있었을 때 실제로 그쪽을 고른 비율"**(득점 ÷ 10)로
정규화됩니다. 가장 높은 결이 주 유형, 두 번째가 보조 유형, 가장 낮은 결이 그림자입니다.

## 고치는 법

전부 `index.html` 안의 `<script>` 한 곳에 데이터로 들어 있습니다.

| 상수 | 역할 |
|---|---|
| `TYPES` | 6가지 결의 이름·설명·색·키워드 |
| `Q` | 15개 질문과 선택지. `["유형코드", "선택지 문구"]` 형태 |
| `BOOKS` | 유형별 추천 도서 3권 |
| `SHADOW_BOOK` | 그림자로 나왔을 때 권하는 책 |
| `DEPTH_BOOKS` | 유형과 무관한 무의식 관련 도서 |
| `CHECKS` | 자기 점검 체크리스트 문항 |

질문을 더하거나 뺄 때는 유형별 등장 횟수를 맞춰주세요. 화면에 표시되는 비율은
`MAXHIT`(각 유형이 등장하는 문항 수)로 자동 정규화되므로 개수가 조금 어긋나도 동작은 하지만,
같은 횟수로 맞춰야 유형 간 비교가 공정합니다.

## 면책

심리 검사나 진단이 아닙니다. 융의 유형론과 그림자 개념에서 착안한 **자기 관찰 도구**이며,
결과는 그날의 컨디션에 따라 달라질 수 있습니다. 시간을 두고 여러 번 해본 뒤 바뀌지 않고 남는
결이 있다면 그쪽이 조금 더 믿을 만합니다.
